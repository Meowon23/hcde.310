Art Institute of Chicago Search

A small web app for anyone who wants to look up artworks 
in Art Institute of Chicago's collection by entering desired keyword

#How to run it
1. Open a terminal in the `hw4` folder 
2. Install what the app needs (only once) pip install flask requests
3. Start the app by running this code in the terminal "flask --app app run`
4. Open  link it prints (usually http://127.0.0.1:5000) in your browser
5. Type word like "lion" or any word you want and press Search. 
- Press Ctrl+C in the terminal to stop.
